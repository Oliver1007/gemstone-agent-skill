# Private distribution boundary

The project owner has asserted ownership or authorized use and private redistribution of the required project Skill, runtime, adapter, Engine, configurations and project-owned normal-use assets. This repository is intended only for the owner and authorized collaborators in an owner-controlled **private** repository. No public redistribution permission is inferred.

Unknown additional source or assets must be excluded and reported for owner confirmation. The source manifest identifies the bounded included runtime and fixture; this assertion is not an independent legal provenance audit.

Third-party dependencies are installed by package manager under their own licenses. Three.js is not vendored. Keep its normal license and package metadata. Node.js, pnpm, PowerShell and the browser are separately installed system dependencies, not repository assets.

Normal operation instructions: [runtime/portable-runtime.md](runtime/portable-runtime.md). Technical smoke results are not qualification or Profile promotion. Historical reports keep their original status; new packaging does not supersede material qualification decisions.
